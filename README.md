# Hidayeti Prinç — Static Website

Responsive, bilingual (Turkish/English) catalogue website for Hidayeti Prinç Basmati rice products.

## Features
- Five catalogue items: Hidayeti Prinç in 5 kg and 10 kg; Buharı Prinç in 5 kg, 10 kg, and 40 kg.
- Click or tap to turn package cards; Enter/Space also flips a focused package. Hover adds gentle depth without hiding the front.
- Front and back package illustrations are stored as PNG files under `assets/products/`.
- Turkish home page (`index.html`) and English version (`en/index.html`).
- Light/dark theme follows system preferences and has a manual toggle.
- Product search, family filters, pack-size filters, and product-specific WhatsApp inquiry links.
- Local product editor; no checkout, payments, or backend.

## Preview
Extract the entire folder and open `index.html` in a browser. If a browser restricts local file behavior, run a local server from this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`. Keep the folder structure intact so `styles.css`, `app.js`, `data/products.js`, and `assets/` remain available.

## Easy product editing (no HTML needed)

Open `editor.html` from the website folder (or visit `/editor.html` on your local preview server).

1. Choose a product to edit, or click **+ Add product**.
2. Fill in both language names/descriptions, brand and pack size.
3. Place front/back images in `assets/products/` and enter their paths in the form. A front-image preview helps check your path.
4. Click **Save product**, then **Download products.js**.
5. Replace `data/products.js` with the downloaded file. Refresh the website to see the new catalogue.
6. Upload the changed catalogue and any new images to your hosting when ready.

**Save product** updates the editor session only. Download before closing; the editor does not write files or publish automatically. Opening the editor again loads the catalogue currently in `data/products.js`. Keep a copy of your previous catalogue if you want an undo after replacing the file. The editor preserves business contact settings when exporting. New pack sizes appear in the site's size filter automatically.

**Türkçe:** `editor.html` dosyasını açın. Ürün seçin veya ekleyin, bilgileri doldurup **Save product** düğmesine basın. **Download products.js** ile indirdiğiniz dosyayı `data/products.js` ile değiştirin. Yeni fotoğrafları `assets/products/` içine koyun. Değişen dosyaları yayınlayınca siteniz güncellenir.

Products are generated by `app.js` from `data/products.js`; that is why the individual cards are not written in `index.html`. Both language pages share this single catalogue.

## Product catalogue
Edit `data/products.js` to update product names, descriptions, weights, and image paths. Each product has `image` (front) and `backImage` (back) PNG assets. The current packaging artwork is a polished visual design; replace it with the approved production packaging artwork before presenting package-label details as final.

## Business contact
WhatsApp inquiries are configured for `+90 534 464 1463`. Update `window.SITE_CONFIG` in `data/products.js` if the contact number changes.

## Before publishing
- Confirm all package artwork and label details against the actual products.
- Add the production domain to canonical metadata and `sitemap-template.xml`.
- Add verified business contact details if you want them displayed publicly.
- Test both language pages and light/dark themes on mobile and desktop.

## Motion
`motion.js` enhances the existing design with a masked word entrance, framed hero reveal, viewport-triggered package entrances, and pointer-responsive package depth. Click, tap, Enter or Space turns a package; hovering leaves the front available to inspect. Motion is disabled for reduced-motion preferences, including changes made while the page is open. No animation libraries are required.

## Motion refinement
- Masked word-by-word hero title and a sweeping image reveal on arrival.
- Pointer-responsive depth for the hero and packages on desktop; no pointer effects on touch screens.
- Staggered catalogue entrances as cards reach the viewport, section-heading wipes, and a quiet reading-progress line.
